# AutoEnglish Learning Center Website

This project is the front-end website for AutoEnglish, an English learning center focused on helping children, teens, and adults build confidence in speaking English. It is a marketing and information website, not a full LMS or online classroom system.

What the website actually does:
- Presents the AutoEnglish brand and learning philosophy
- Shows the main learning programs: Calistung, AutoToddler, AutoKids, AutoTeens, and AutoSpeak
- Explains the benefits of the program and the learning journey
- Displays class gallery content and student-focused visuals
- Provides contact details, WhatsApp registration, Instagram, email, TikTok, and map location
- Includes a floating AI-style chat assistant named Auto AI that answers common questions about programs, pricing, registration, location, and affordability
- Uses smooth scrolling and responsive sections for desktop and mobile users

## Project purpose

This is a static React + Vite landing page for an English education business in Bogor, Indonesia. The site is designed to attract prospective students and families, explain the courses, and encourage them to contact the center for enrollment or a free trial class.

## Features

- Hero section with strong call-to-action and scroll navigation
- Multi-age program cards for different learner stages
- About section explaining the center's mission and teaching philosophy
- Why AutoEnglish section highlighting strengths like expert educators and adaptive learning
- Learning journey timeline across age groups
- Gallery section with learning environment images
- Contact section with social links and embedded location map
- Floating chat assistant for quick FAQs
- Mobile-responsive navigation and animations

## Tech stack

- React
- Vite
- TypeScript
- Tailwind CSS
- Framer Motion / motion-react
- Lucide React icons
- shadcn-style UI components

## Getting started

Install dependencies:

```bash
npm install
```

Start the local development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```

Deploy to GitHub Pages:

```bash
npm run deploy
```
